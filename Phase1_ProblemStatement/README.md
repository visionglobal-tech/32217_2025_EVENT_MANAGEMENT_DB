# Phase I: Problem Statement & Objectives

### Problem Definition
Managing community, academic, and corporate events manually using basic tools leads to capacity tracking challenges, registration overlaps, and unorganized venue allocations.

### Target Users
- Event Organizers
- System Administrators
- Registered Attendees

### Project Objectives
- Establish a structurally sound, 3NF normalized relational database structure.
- Automate constraint validations using core PL/SQL programming.
- Implement reliable security and audit restrictions.
